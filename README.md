# CivicFix AI

Smart Civic Issue Reporting System

CivicFix AI is an end-to-end, multi-agent AI system designed to streamline civic issue reporting. It analyzes citizen complaints, classifies them, detects duplicates, recommends routing to the correct department, drafts formal complaints, and monitors them for necessary follow-up.
